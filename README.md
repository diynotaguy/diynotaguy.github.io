I had to learn how to animate using CSS, which was very interesting because before today I didn't realise that CSS could provide that sort of functionality. 
One thing I struggled with was the syntax: quite a lot of the errors I made were from not closing curly brackets in the CCS or from not adding a closing tag in HTML. I think with more time, I'll get better at reducing and spotting those errors. Also, I was quite unused to the hierarchy of HTML where everything has a parent, so I had to figure out how to do that along the way, and I think you'd be able to see from the commits that my programming got more efficient and started to make more sense in the last two commits or so.
